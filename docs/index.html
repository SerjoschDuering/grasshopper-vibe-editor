Quick Start Guide

Step 1: Download & Install
  1. Download the app for your Mac type
  2. Install the .dmg like any Mac app
  3. Download the Grasshopper component
Step 2: Connect & Code
  1. Open the .gh file in Grasshopper
  2. Set server toggle to "True"
  3. Launch VibeCode app and start coding!

System Requirements

Desktop App
  • macOS 10.14+ or Windows 10+
  • Intel/Apple Silicon/x64
  • ~125-170MB disk space
Grasshopper
  • Rhino 7 or 8 (Windows/Mac)
  • Grasshopper plugin
  • Python scripting enabled
