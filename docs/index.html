Getting Started

Quick Setup
  1. Download the app for your platform above
  2. Download the Grasshopper component
  3. Open the .gh file in Grasshopper and set server toggle to "True"
  4. Launch VibeCode app and start coding!
First-time install? You'll see security warnings - get help below ↓

Need Help?

Security Warnings

Getting "can't be opened" or "Windows protected your PC"? This is normal for unsigned apps.

macOS: System Settings → Privacy & Security → "Open Anyway"
Windows: Click "More info" → "Run anyway"
