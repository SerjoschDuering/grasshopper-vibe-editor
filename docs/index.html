Quick Start Guide

Step 1: Download & Install
  1. Download the app for your platform above
  2. Install (you'll see security warnings - see help below)
  3. Download the Grasshopper component
Step 2: Connect & Code
  1. Open the .gh file in Grasshopper
  2. Set server toggle to "True"
  3. Launch VibeCode app and start coding!

Installation Troubleshooting

macOS Security Warning
Error: "VibeCode Grasshopper Editor is damaged and can't be opened"
Solution:
  1. Go to System Settings → Privacy & Security
  2. Scroll to the Security section
  3. Look for the blocked app message
  4. Click "Open Anyway"
  5. Click "Open" in the confirmation dialog

Apple's Official Guide

Windows SmartScreen
Warning: "Windows protected your PC"
Solution:
  1. Click "More info" in the SmartScreen dialog
  2. Click "Run anyway"
  3. The installer will proceed normally
  4. Some antivirus may also show warnings - these are false positives

Microsoft's Official Guide

Why do these warnings appear?

Code signing certificates cost $99-400/year per platform. As a free, open-source project, we don't purchase these certificates. The app is completely safe - it's just not "officially blessed" by Apple/Microsoft. This is standard for many popular open-source desktop applications.
