Why VibeCode?

Modern Python editing for Grasshopper developers

Overview

  • Desktop app talks to a GH server
  • Select a component to fetch code/params
  • Edit, generate with AI, send back instantly

Code Tab

  • Generate IronPython 2.7 with GPT‑5
  • Add/edit/remove inputs and outputs
  • One‑click "Send to GH" with live sync

Context Tab

  • Export canvas as Markdown/JSON/XML
  • Select scope and detail, +1 hop neighbors
  • Sorted by execution order with filtering

Getting Started

Quick Setup
  1. Download the app for your platform above
  2. Download the Grasshopper component
  3. Open the .gh file in Grasshopper and set server toggle to "True"
  4. In VibeCode → Config, paste your OpenAI API key (optional; required for AI code generation)
  5. Launch VibeCode app and start coding!
First-time install: Security prompts

Unsigned apps trigger warnings on macOS/Windows.

  • macOS: System Settings → Privacy & Security → "Open Anyway"
  • Windows: Click "More info" → "Run anyway"
